# hxyfront-62007 植物标本馆入库

源提示词编号：9

植物标本馆压制标本入库前端，覆盖 **鉴定放行 → 尺寸匹配上柜 → 封存归档 → 复核退回 → 柜位清理** 的完整闭环。工作人员可录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态、标本尺寸与馆藏位置；页面包含入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 闭环业务规则

1. **上柜前置条件**：标本必须压制完成且鉴定为「接受」，才允许占用柜位。
2. **尺寸匹配**：柜位按标本尺寸严格匹配 —— 小号 S→A 区、中号 M→B 区、大号 L→C 区。
3. **容量不足整次拒绝**：批量上柜先干跑预检，任一标本无匹配空余柜位时，整批不分配、不封存，任何现有占用保持不变（事务在草稿副本上执行，失败丢弃）。
4. **重复上柜幂等**：已占柜/已封存的标本自动跳过，重复选择同一标本不会产生重复占用。
5. **改判释放**：鉴定改判为存疑或退回时，释放未封存标本占用的柜位，但鉴定历史完整保留（含释放的柜位号）。
6. **封存复核**：已封存标本只能由「接受」复核退回为「退回」，终生一次；退回后原柜位标记 **待清理**，不能立即复用，须人工「确认清理」后才恢复空余。
7. **持久化**：所有状态写入 localStorage，刷新页面后占用、封存、待清理状态仍在。

## 页面

- **入库队列**：标本登记（含尺寸档位）、压制/鉴定/上柜/封存快捷操作、鉴定状态筛选与关键字检索。
- **批量上柜**：勾选可上柜标本，实时显示各尺寸「需求 / 空余」，容量不足提前预警，提交走原子事务。
- **馆藏柜位**：A/B/C 三区柜位图，空余 / 已占用 / 待清理三色状态，待清理柜位可一键确认释放。
- **采集地点**：按采集点汇总海拔、生境、采集人与关联标本。
- **单份标本详情**：完整字段、当前/原柜位、复核退回机会、鉴定历史时间线。
