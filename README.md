# hxyfront-62007 植物标本馆入库

源提示词编号：9

植物标本馆压制标本入库前端：录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态、标本尺寸与馆藏位置；包含入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 鉴定放行与柜位封存闭环规则

1. **上柜门槛**：标本必须压制完成（已压制/已封存）且鉴定结论为「接受」才能占用柜位。
2. **尺寸匹配**：柜位分小/中/大三格，格位规格 ≥ 标本尺寸才可放入；大件优先分配。
3. **容量不足整次拒绝**：批量上柜先模拟分配，任一标本无匹配空闲格位则整次失败，不改变任何占用（事务性）。
4. **改判释放**：鉴定改判为「存疑/退回」时立即释放**未封存**标本的柜位；每次改判都追加鉴定历史，历史只增不改。
5. **封存与复核退回**：已占柜的接受标本可封存；已封存标本只能**复核退回一次**（`reviewReturned` 终身标记），退回后：
   - 标本回到未封存、鉴定退回；
   - 原柜位进入「待清理」，不能立即被新标本复用；
   - 工作人员现场清理后格位才恢复空闲。
6. **幂等上柜**：对已占用柜位的标本重复上柜不会产生重复占用，批量时自动跳过。
7. **持久化**：所有状态写入 localStorage，刷新页面后占用、封存、待清理与鉴定历史均保留。

## 技术栈

React 19 + Vite + TypeScript，Vitest（jsdom）单元/闭环测试。

## 本地运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:62007
npm test         # 运行 23 项领域与 UI 闭环测试
npm run build    # 类型检查 + 生产构建
```

开发端口：62007
